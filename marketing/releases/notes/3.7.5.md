## en-US

- Use supported Codex, Claude Code, or Antigravity tools already installed and signed in on your Mac—no separate API key needed in VOpenKey AI.
- See the assistant’s progress and wait time, then create images with Codex and copy or insert them into your work.
- Review a text shortcut’s full expansion on the suggestion bar before choosing to use it.
- Get updates from GitHub releases, with controls for automatic downloading and installation.
- Close Settings with ⌘W.

## vi

- Dùng Codex, Claude Code hoặc Antigravity đã cài và đăng nhập trên máy Mac làm trợ lý AI mà không cần nhập API key riêng vào VOpenKey AI.
- Theo dõi tiến trình và thời gian chờ của trợ lý; dùng Codex tạo ảnh rồi sao chép hoặc chèn vào nội dung đang làm.
- Xem trước nội dung gõ tắt trên thanh gợi ý và chọn có mở rộng hay không.
- Cập nhật ứng dụng từ GitHub Releases, với tùy chọn tự động tải và cài đặt.
- Nhấn ⌘W để đóng cửa sổ Cài đặt.
